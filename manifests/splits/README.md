# Evaluation splits

The generated `synthetic-000` sample serves as the fixture test case. It has no
subject identity and is excluded from scientific estimates.

After obtaining authorized human scans, freeze and hash a split file mapping
subject or identity group to one split. Keep all captures, views, environments,
and render seeds for an identity together. Freeze view tuples and record exclusions
with reasons before evaluation. The proposed THuman 400/50/50 counts depend on the
verified cohort. Freeze generic regression scenes separately.
